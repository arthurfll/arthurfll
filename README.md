## Sobre

DevOps com foco em infraestrutura cloud-native — entrega contínua, containers e plataformas resilientes sobre AWS. Trabalho na interseção entre confiabilidade de plataforma e velocidade de times de desenvolvimento, usando .NET e Kubernetes como principais ferramentas do dia a dia.
